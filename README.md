# Доставка таймер (Android)

## Сборка APK в Android Studio
1. File → Open → выбрать папку DeliveryTimer.
2. Дождаться синхронизации Gradle.
3. Build → Build App Bundle(s) / APK(s) → Build APK(s).
4. APK: app/build/outputs/apk/debug/app-debug.apk — скинуть на телефон и установить.

## Сборка без Android Studio (GitHub)
Залить папку в репозиторий GitHub → вкладка Actions → "Build APK" → скачать артефакт DeliveryTimer-apk.

## Изменить интерфейс
Весь интерфейс — app/src/main/assets/index.html.
